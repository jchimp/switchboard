New terminal, from anywhere

Ctrl+Alt+N pops a small palette: pick a profile, Enter. Name and color are auto-assigned (next unused hue), directory defaults to the last one you used, and it's registered so the strip shows it immediately. Untick "keep" for a throwaway that disappears from the registry when it closes.

Press N in the desktop below to try it.

A · Edge strip

An 8px strip hugs the left screen edge, one colored segment per terminal — the active one glows. Hover (or Ctrl+`) slides out a rail of live DWM thumbnails with name, shell, working dir, and a number key. Zero taskbar footprint; the strip doubles as a passive status bar.

Top-edge variant: the strip runs along the top and the rail drops down as a horizontal row of wider thumbnails — better on an ultrawide, and it never collides with a left-docked app or the Win11 snap zones. Same registry, same colors; the edge is a setting.

B · Overlay switcher

Nothing on screen until you press the hotkey; then a centered palette with thumbnails, fuzzy search, and 1–6 jump keys. Fastest for muscle memory, and it's the one that works the same on a laptop screen. Pairs naturally with A or C rather than replacing them.

Cost: no passive glance — you can't see that a build finished without opening it.

C · Thin rail

A 54px dock that's always visible: color bar + two-letter tag per terminal, tooltip on hover. Terminal window nudges right to fit. Feels like a VS Code activity bar, so it's familiar, and it's the easiest to build first.

Cost: permanent screen real estate, and on one monitor it competes with whatever you'd dock on the left.
